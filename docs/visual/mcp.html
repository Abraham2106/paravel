MCP local de lectura

pack + chat = asiento → Iniciar → pantalla de espacio → MCP (después, acotado)

Hay código de crates, no un plan vacío. Cero MCP en Paravel.exe (Tauri). Aceptación del cliente local pendiente. No reconstruye Grok Bot. Oira y Alira son inquilinos de la sede.

Hay código

Transporte
stdio · rmcp 3.4.0

Estado WBS 4
No aceptado

El asiento
No es MCP
El Bot se sienta en pack + chat. MCP no inicia mesas ni Bots.
01 ajeno

Cliente local

Entregable

Una entrada mcpServers con exe, DB absoluta y UUID de una mesa. Plantilla: cursor-mcp.example.json.

Se espera

initialize → tres tools. El operador elige mesa; el modelo no. Cursor u otro: no hay cliente aceptado.

No es

Grok Bot, la UI de Paravel, ni un mapa de la sede. Cerrar Tauri no mata este proceso.

Reutilizable

El formato stdio, sí. La mesa y las rutas son privadas.

02 binario propio

paravel-mcp

Entregable

Servidor rmcp = "=3.4.0" (server + transport-io). Stdin/stdout = JSON-RPC. Stderr = diagnóstico. Tope de trama 64 KiB.

Se espera

EOF cierra. --help / --version no abren DB. Reiniciar conserva el UUID del argv. Protocolo de referencia: 2025-11-25.

No es

Sidecar Tauri, HTTP, túnel, servicio 24/7. No vive en app/src-tauri.

Reutilizable

El SDK, sí. El exe y las tools son Paravel.

03 biblioteca

paravel-context

Entregable

Reader::open con SQLITE_OPEN_READ_ONLY. Cada llamada vuelve a comprobar espacio + pack_pieza. Sin migraciones ni seed.

Se espera

Mesa ajena o pieza no invitada: NOT_FOUND_OR_NOT_VISIBLE. Pack vacío = cero piezas. La nota sigue visible.

Tauri

Comparte DTOs de ui. Conserva CRUD, Iniciar y list_spaces. Compartir crate no comparte privilegios.

Reutilizable

Consultas y DTO, sí. El esquema es de Paravel.

04 una mesa

SQLite

Entregable

Sede → grupo → espacio → piezas. Relación pack_pieza. Oira/Alira = inquilinos. CTO = sede, no una mesa.

Se espera

Tauri crea y mantiene la DB. MCP abre la que ya existe. Schema incompatible: SCHEMA_UNSUPPORTED, sin reparar.

No autoriza

marcada es de Iniciar. bot_activo es de la UI. Ninguno abre el pack al MCP.

Reutilizable

No. El modelo es Paravel, no kit.

Tres tools — contrato v1

leer_espacio
Nota de la mesa
Entrada {}. Sale id, nombre, grupo (etiqueta), nota, conteo de compartidas. Sin inventario de sede.
listar_piezas
Página del pack
limite 1–100 (50). cursor ligado al espacio. Solo piezas actuales de pack_pieza: id, nombre, kind.
leer_contexto_pieza
Payload persistido
pieza_id UUID. Rutas y URLs son datos: no se abren, no hay fetch, no hay adaptador.

Pack frente a MCP frente a Iniciar

Pack + chat
Asiento del Bot
Humano copia y pega en el chat. Independiente. No es una tool MCP.
MCP
Lectura después
Cliente local llama tools sobre esa mesa. No sienta al Bot. No lanza nada.
Iniciar
Kit Tauri
invoke → Rust → Code.exe / firefox.exe. MCP no registra iniciar_espacio.
Revocar
Pack ≠ nota
Quitar pack oculta piezas. La nota queda hasta desconectar y matar el proceso.

Qué no hace — nunca en esta fase

  • Iniciar, spawn, argv, shell
  • listar_espacios u otras mesas
  • SQL libre, path, command
  • Abrir archivos, carpetas, PDFs
  • Fetch de URLs o Notion
  • Escribir pack, CRUD, migrar
  • Puente a Grok Bot / VM remota
  • HTTP, OAuth, 24/7, red
