Paravel

Etapas y capas

1 pack + chat → 2 Iniciar → 3 pantalla de espacio → 4 MCP (después)

Las capas no cambian de etapa a etapa. Lo que cambia es qué se entrega y si el artefacto sirve fuera de Paravel. MCP no es el asiento. Tauri v2 ya está cerrado.

01 ahora · uso

Pack + chat

Entregable

Un Bot sentado en una carpeta local. Pack = notas, archivos y payloads de esa mesa. Prompt de rol: no eres el CTO.

Se espera

¿El pack alcanza para trabajar? ¿El Bot usurpa al CTO o se queda en su mesa?

Uso

Validar la tesis con conversación real. Sin app. Sin tools. El chat es el producto Grok Bot; Paravel solo decide qué carpeta se le da.

Reutilizable

El gesto sí. No hay binario propio. No es kit.

02 siguiente · kit

Iniciar

Entregable

Tauri mínimo. Code.exe + carpeta. firefox.exe + dos URLs. Log con el argv exacto. Sin code.cmd, sin shell.

Se espera

Pegar el argv del log en una terminal produce el mismo resultado. Error claro si el .exe no está.

Uso

Abrir VS Code / Cursor / Firefox desde cualquier launcher futuro. Sirve hoy, antes de que exista la sede.

Reutilizable

Sí — kit launch-host. Otros proyectos pueden copiarlo entero.

03 producto

Pantalla de espacio

Entregable

SQLite grupo / espacio / pieza. UI de mesa: marcar una o todas, Iniciar en la esquina. Diálogo nativo de carpeta.

Se espera

Entrar a un espacio, marcar piezas, play. Lo no marcado no se abre. El modelo deja de moverse cada semana.

Uso

Paravel como sede. Ahí viven los inquilinos. El play llama al kit de la etapa 2; no lo reescribe.

Reutilizable

Tiles y play, sí. El esquema SQLite es Paravel, no kit.

04 pospuesto

MCP lectura

Entregable

Tools de lectura sobre la misma capa Rust. Filtro por espacio_id. No registrar iniciar_espacio.

Se espera

El Bot lee el pack por tubería tipada, no por volcar la carpeta al prompt. Acceso auditable.

Uso

Mejora opcional del asiento. No sustituye pack + chat. No se construye hasta que 1–3 estén estables.

Reutilizable

El servidor MCP genérico, sí. Las tools son Paravel.
